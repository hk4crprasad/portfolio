The adjacent declarations type their public props for the TypeScript application. Adaptations add a canvas text fallback, an accessible portrait toggle, inert hidden content and loop copies, keyboard focus styles, and offscreen/background pausing. The application motion provider follows the system reduced-motion preference and lets visitors pause all effects; no preference is stored or sent anywhere.
